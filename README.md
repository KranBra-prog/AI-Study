# 🤖 AI Study Buddy

**AI Study Buddy** es una aplicación interactiva construida con Python, Streamlit y la API de OpenAI. Permite a los estudiantes subir sus apuntes en formato PDF o texto y transformarlos automáticamente en resúmenes, cuestionarios (quizzes) y fichas de estudio (flashcards).

---

## 🚀 Características

- 📌 **Resúmenes automáticos:** Genera explicaciones concisas y estructuradas a partir de tus notas.
- ❓ **Cuestionarios interactivos:** Crea preguntas de opción múltiple configurables (de 1 a 10 preguntas).
- 🎴 **Flashcards:** Sintetiza conceptos en formato de tarjetas de estudio (término / definición).
- 📄 **Soporte multiformato:** Carga archivos `.pdf`, `.txt` o pega el texto directamente.

---

## 🛠️ Tecnologías utilizadas

- **Python 3.x**
- **Streamlit:** Interfaz gráfica web interactiva.
- **OpenAI API (`gpt-4o`):** Generación de contenido con Inteligencia Artificial.
- **PyPDF2:** Extracción de texto desde archivos PDF.
- **python-dotenv:** Manejo seguro de variables de entorno.
